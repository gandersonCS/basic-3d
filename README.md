# Basic 3D Exercise
A starter project for exploring 3D rendering in MonoGame.

The associated written tutorial can be found at [https://textbooks.cs.ksu.edu/cis580/13-basic-3d-rendering/index.html](https://textbooks.cs.ksu.edu/cis580/13-basic-3d-rendering/index.html)

This tutorial was created for the CIS 580 - Foundations of Game Programming course offered by the [Department of Computer Science](https://cs.ksu.edu) at [Kansas State University](https://ksu.edu)
